# 📘 Инструкция: как править сайт

Сайт: **https://moroz-portfolio.github.io/**

---

## 1. Из чего состоит

| Файл | Зачем нужен |
|---|---|
| `index.html` | сам сайт и редактор. Меняется только при доработках кода |
| `content.js` | всё содержимое: тексты, ссылки, материалы портфолио. Пишется редактором автоматически |
| `fonts/` | шрифт сайта (лежит локально, ничего грузить не нужно) |
| `photo-sample.jpg` | картинка-заглушка (ваше фото вшито в `content.js`) |

---

## 2. Как войти в редактор

Откройте сайт и добавьте к адресу `?edit=1`:

**https://moroz-portfolio.github.io/?edit=1**

Появится окно «Введите пароль». После ввода страница становится редактируемой: внизу слева появляется плашка, тексты начинают подсвечиваться при наведении.

Пароль держится 2 часа (настраивается в ⚙ → «Пароль»).

---

## 3. Правка текста — кликом по странице

- Наведите курсор на любой текст — он обводится пунктиром.
- Кликните — и печатайте прямо в нём. Сайт обновляется сразу.
- **Enter** — закончить (в однострочных полях), **Esc** — отменить правку.
- Жирный текст: в абзацах «О себе» можно оставить пометки `**вот так**` — они станут жирными.

Правятся: заголовок первого экрана, подзаголовки, бейджи, цифры, услуги, названия публикаций, абзацы «О себе», контакты, подвал, пункты меню.

---

## 4. Правка ссылок

- Наведите курсор на ссылку — в углу появится значок 🔗.
- **Alt + клик** (на Mac — **Option + клик**) → откроется поле с адресом → измените → Enter.
- **Ctrl + клик** по ссылке — открыть её в новой вкладке (проверить, куда ведёт).

Так меняются: пункты меню, кнопки, все публикации, контакты, соцсети в подвале.

---

## 5. Плашка снизу слева

| Кнопка | Что делает |
|---|---|
| статус | «сохранено в 12:34» / «сохраняю…» / текст ошибки |
| ⚙ | настройки и структура (см. ниже) |
| ✏️ | включить/выключить правку кликом |
| ↺ | сбросить черновик |
| ✕ | выйти из редактора |

---

## 6. Что в настройках (⚙)

- **Сохранение на сайт** — статус, «Проверить запись», «Отключить», «Сохранить сейчас».
- **Пароль на редактор** — сменить или убрать.
- **Оформление** — два цвета, тема, размер шрифта.
- **Фото в первом экране** — загрузка с компьютера, инициалы, подпись.
- **Меню** — ссылки пунктов.
- **Кнопки первого экрана** — ссылки и вид.
- **Цифры** — сколько их и порядок.
- **Услуги** — сколько их и порядок.
- **Публикации** — тип, ссылка, добавить/удалить; здесь же редактируются сами типы (фильтры).
- **Абзацы «О себе»** — сколько их.
- **Контакты** — ссылки кнопок и чипов.
- **Подвал** — соцсети.
- **Блоки на странице** — включить/выключить блок целиком.

Тексты в настройках специально не дублируются: они правятся кликом на странице.

---

## 7. Сохранение — автоматическое

Никакие файлы загружать не нужно.

1. Один раз подключите доступ: ⚙ → «Сохранение на сайт» → вставьте токен → «Подключить автосохранение».
2. Дальше любая правка уходит на сайт через ~2 секунды после того, как вы перестали печатать.
3. Сайт обновляется за 1–2 минуты.
4. **Ctrl + S** — сохранить немедленно.

### Как получить токен

Проще всего классический:

1. Откройте https://github.com/settings/tokens/new
2. **Note:** `portfolio-editor`
3. **Expiration:** No expiration
4. Поставьте галочку **`repo`**
5. **Generate token** → скопируйте (`ghp_...`)

Важно: токен должен быть создан в том аккаунте, которому принадлежит репозиторий (`moroz-portfolio`).

Если делаете fine-grained токен: Repository access → Only select repositories → `moroz-portfolio/moroz-portfolio.github.io`, Permissions → **Contents: Read and write**.

Токен хранится только в вашем браузере, в файлы сайта не попадает.

---

## 8. Черновики

Пока правка не ушла на сайт, она лежит в памяти браузера. Если открыть редактор на другой версии сайта, устаревший черновик отбрасывается автоматически — он не может затереть свежий контент. Кнопка ↺ сбрасывает черновик вручную.

---

## 9. Частые проблемы

| Проблема | Решение |
|---|---|
| «не сохранено: GitHub не принял токен / Resource not accessible» | У токена нет права записи. Создайте классический токен с галочкой `repo` (п. 7). |
| «не сохранено: Файл одновременно меняется…» | Открыты две вкладки редактора — закройте лишние, нажмите «Сохранить сейчас». |
| «не сохранено: нет связи с GitHub» | Проверьте интернет и повторите. |
| Панель не открывается | Ctrl+Shift+R на странице `?edit=1`. |
| Забыл пароль | В `content.js` замените `"passwordHash": "sha256$…"` на `"passwordHash": ""`, обновите страницу и задайте новый. |
| Изменения не видны на сайте | Откройте сайт с Ctrl+F5, подождите 1–2 минуты после сохранения. |

---

## 10. Если правите руками

`content.js` — обычный текст: `window.SITE_CONTENT = { … }`. Структура повторяет `DEFAULT_CONFIG` внутри `index.html`. После ручной правки загрузите файл в репозиторий: **Add file → Upload files → Commit changes**.
